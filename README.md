## Features

### 1. Личный кабинет пользователя
Единая точка входа для пользователей: регистрация, авторизация, управление профилем и просмотр истории действий.

### 2. Биллинг и управление тарифами
Автоматический учёт использования ресурсов, выставление счетов, просмотр баланса и платежей в реальном времени.

### 3. REST API и интеграции
Документированный API (OpenAPI/Swagger) для интеграции с внешними сервисами и автоматизации рабочих процессов.
